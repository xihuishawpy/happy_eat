# Happy Eat 功能清单与回归测试检查表

> 本文档按模块完整记录当前 `happy_eat` 的所有前端交互、业务规则、孕期守护、点菜与买菜规划、AI/语音能力、API 边界与自动化测试覆盖，便于后续迭代时快速回归验证。

## 快速回归命令与入口

- **自动化单元测试（API + Netlify + Cloudflare Worker）**：`npm test`
- **完整回归（含 Playwright 移动端浏览器 UI 测试）**：`RUN_PLAYWRIGHT_UI=1 npm test`
- **生产构建校验**：`npm run build`
- **本地开发服务**：`npm run dev`（默认开发访问码 `happy-eat`）
- **线上生产站点**：`https://happy-eat-shaw.netlify.app/`

## 模块 1：访问门禁与会话鉴权（AccessGate & Auth）

核心代码：`src/App.jsx`（`AccessGate`、初始化 `useEffect`）、`netlify/functions/api.mjs`（`handleSession`）

- [ ] **未登录拦截**：首次打开且 `localStorage` 无 `familyAccessToken` 时展示「打开家庭空间」登录页；未授权调用业务 API 返回 `401`。
- [ ] **访问码验证**：输入错误访问码提示「家庭访问码不正确」；输入正确访问码写入 `localStorage.familyAccessToken`，拉取 `/api/app` 进入「今天」首页。
- [ ] **登录限流**：同一 IP 在 60 秒内连续输错 10 次访问码，返回 `429 尝试次数过多，请稍后再试`；登录成功后清零失败计数。
- [ ] **会话持久化与失效恢复**：刷新页面自动免密进入；若服务端访问码变更导致 `/api/app` 返回 `401`，自动清除本地 token 并退回登录页。
- [ ] **加载与异常兜底**：首屏请求期间显示加载卡片；接口报错时显示「家庭空间暂时无法打开」错误卡片及「重新加载」按钮。
- [ ] **服务端配置缺失保护**：未配置 `FAMILY_ACCESS_CODE` 时直接返回 `503`。

- [ ] **全家共享「买菜清单」卡片（`ShoppingPlanCard`）**：

## 模块 3：「食材」库存管理

核心代码：`src/App.jsx`（`activeTab === "ingredients"`、`CategoryRail`、`IngredientTile`、`IngredientEditorSheet`）、`src/foodEmoji.js`

### 3.1 顶栏与搜索
- [ ] **顶部统计**：准确显示「共 N 种 · M 种需尽快用掉」（无急用食材时显示「共 N 种可用食材」）。
- [ ] **搜索切换与别名归一**：点击放大镜展开/收起搜索栏（收起时清空关键词）；支持同义别名搜索（如 `西红柿→番茄`、`青葱/小葱→葱花`、`马铃薯→土豆`、`西蓝花→西兰花`、`酱油→生抽`、`花生→花生米`），支持输入框内「×」一键清空。

### 3.2 自然语言批量录入（重点防回归）
- [ ] **手动打字不提前触发识别**：逐字输入（含拼音首字母 `j` 等中文 IME 过程）时，`<textarea>` 始终保持挂载与焦点，**不会**提前弹出「识别到 N 种，确认后加入」预览卡片。
- [ ] **显式触发识别预览**：输入文字后下方展示「清空 / 识别食材」；点击「识别食材」（或非 IME 合成态按 `Enter`，`Shift+Enter` 保留换行）后进入识别确认卡。
- [ ] **语音与示例直达预览**：语音转写完成（带 `🎙` 引用）或点击「✨ 试试示例」（带 `📝` 引用）后，直接展示识别确认卡。
- [ ] **预览卡交互**：
  - 展示识别数量、每项食材 Emoji/规范名/分类/状态标签（快过期/优先用/冷冻）。
  - 点击单个芯片右侧「×」可将该项从本次待加入列表剔除；全部剔除后「全部加入」按钮禁用。
  - 点击「修改」回到输入框保留原文本并自动聚焦光标至末尾，且重新编辑后重置剔除记录。
  - 点击「全部加入」提交 `/api/ingredients/batch`（配置了 LLM 时走智能解析，否则降级本地正则），已存在的同名食材更新分类并在新状态非 `none` 时更新状态，新食材追加并即时重算菜谱。

### 3.3 分类导航与 Emoji 瓷砖网格
- [ ] **吸顶分类胶囊**：`.ingredient-tools-sticky` 滚动时吸顶；显示「全部」及有食材的分类（蔬菜、肉禽蛋、主食、调味、乳品、其他）与实时计数。
- [ ] **分组 vs 平铺视图**：选「全部」且无搜索词时，顶部优先分组展示「⏰ 尽快用掉 · 特殊状态」（按快过期 → 优先 → 冷冻排序），其下按 6 大分类展示普通状态食材；选中具体分类或输入搜索词时平铺展示匹配结果。
- [ ] **空状态**：搜索/筛选无结果时显示空状态卡片并提供「手动添加食材」按钮。

### 3.4 单食材新增 / 编辑 / 删除与全入口孕期安全守护
- [ ] **孕期分级评估双引擎（`shared/pregnancy.js`）**：内置常见中式家庭食材孕期规则库（`safe` 适合孕期 / `caution` 孕期慎吃 / `avoid` 孕期避免 / `unknown` 建议核实，长词优先如 `生鱼片`/`溏心蛋`/`发芽土豆` 命中 `avoid`）；未命中规则的冷门食材在配置 LLM 时由 DeepSeek/DashScope 兜底评估并持久化。
- [ ] **全入口新增必提醒**：
  - **单个新增/编辑弹层**：输入食材名即时显示孕期食用提示卡片（含原因与免责声明）；警示但允许保存（方便家庭其他成员食用）。
  - **自然语言批量识别预览卡**：每颗慎吃/避免芯片高亮标注，下方汇总展示孕期注意事项或「均适合孕期食用」。
  - **提交后全局提醒**：无论通过单食材新增、食材页批量录入、今天首页快捷录入、还是买菜清单一键入库，新增后只要含 `avoid`/`caution`/`unknown` 立即弹出顶部可关闭的「新增食材孕期提醒」卡片；全部安全则在 Toast 中温和确认。
  - **食材瓷砖展示**：开启孕期模式时，仅对 `avoid`/`caution` 食材瓷砖显示「孕期避免 / 孕期慎吃」小标签，避免满屏绿色噪音。
- [ ] **新增食材**：点击右上角「＋」打开弹层，输入名称（必填，≤40 字）、选择分类（默认「自动分类」或 6 选 1）、选择提示状态（普通/优先用掉/快过期/冷冻中）；重复名称提交返回 `409 这个食材已经在清单里`。
- [ ] **编辑食材**：点击任意食材瓷砖打开编辑弹层，实时预览对应 Emoji 与孕期提示；修改名称/分类/状态后点击「保存修改」，重命名时同步重算孕期建议，列表与菜谱匹配即时更新。
- [ ] **删除食材**：点击「删除食材」展开二次确认（「取消 / 确认删除」），取消不删除，确认后从列表移除并即时重算可做菜谱。

## 模块 6：沉浸式「烹饪模式」与做完盘点

核心代码：`src/App.jsx`（`CookingMode`、`highlightStepText`、`playGentleChime`）、`src/foodEmoji.js`（`extractStepTimer`）

### 6.1 深色全屏分步烹饪
- [ ] **顶部控制与分段进度条**：左上角退出、居中菜名、右上角打开总览抽屉；顶部分段进度条可点击任意段直接跳转对应步骤。
- [ ] **关键词高亮与本步食材**：步骤正文自动高亮菜谱中出现的食材名及时间/用量词（如 `2分钟`、`1勺`）；下方展示本步涉及的食材芯片（未提及具体食材时显示「🧺 准备食材 x/y」快捷打开总览）。
- [ ] **内置步骤倒计时器**：
  - 步骤文案含时长（如 `2分钟`、`30秒`、`半小时`）时自动生成对应环形倒计时卡片。
  - 无时长时展示快捷计时胶囊（`+ 1 分钟` / `+ 3 分钟` / `+ 5 分钟`）。
  - 支持开始、暂停、重置、重来；倒计时归零展示「⏰ 时间到！」并播放温和双音提示音（Web Audio API）；切步时自动重置为新步骤时长。
- [ ] **交互手势与防息屏**：
  - 支持左右滑动切换上/下一步（最后一步左滑进入完工盘点）；底部展示「下一步」预览与「上一步 / 下一步（最后一步变为 做好啦，开饭）」大按钮。
  - 支持 Screen Wake Lock API 的浏览器自动保持屏幕常亮并提示「☀︎ 屏幕常亮中」。
- [ ] **进度持久化**：当前步骤索引、已勾选准备食材、已完成步骤自动存入 `sessionStorage`（`happy-eat-cooking-{id}`），退出烹饪模式（未完成盘点）后重新进入完整恢复，且此时后端库存不变。
- [ ] **食材与步骤总览抽屉**：支持勾选准备食材清单、点击任意步骤快速跳转、点击「直接完成烹饪」跳过剩余步骤进入盘点页。

### 6.2 完工盘点与一键撤销
- [ ] **三态食材消耗选择**：列出该菜谱全部必需食材，每项默认「还有（`kept`）」，可切为「剩不多（`low` → 后端标为 `priority`）」或「用完了（`used_up` → 后端从库存移除）」。
- [ ] **提交与跳过**：
  - 「更新食材并完成」提交 `/api/recipes/:id/complete`；「跳过（库存没变化）」全部按 `kept` 提交。
  - 完成后清理该菜谱的 `sessionStorage` 进度、退出烹饪模式并刷新全局匹配。
- [ ] **撤销 Toast**：有库存变更时底部弹出 Toast（显示移除了几项 / 标为优先几项）及「撤销」按钮；点击「撤销」调用 `/api/consumption-events/:id/undo` 恢复被删食材及原状态；同一事件重复撤销后端返回 `409` 防重。

### 7.2 AI 帮我配菜
- [ ] **可用状态判断**：未配置文本 AI Key 或库存为空时，「选食材并生成」按钮禁用并给出提示文案。
- [ ] **自选食材弹层**：点击「选食材并生成」打开「选择想用的食材」弹层，按分类展示现有食材及状态标签；支持多选、「清除选择」；不选时文案为「用全部食材生成」，选中 N 项时为「用已选 N 种食材生成」。

### 7.3 四种导入菜谱入口与「手动写菜谱」
- [ ] **手动写菜谱（自己录入）**：点击「手动写一道自家拿手菜」直接打开空白菜谱编辑器，填写标题、方式、耗时、食材与步骤后调用 `POST /api/recipes` 直接入正式菜谱库并展示详情。
- [ ] **拍照识别**：选择 JPG/PNG/WebP 图片，前端 `compressRecipeImage` 自动压缩（长边 ≤1600px JPEG）并展示缩略图，可附加备注；已配置视觉模型（DeepSeek `deepseek-flash` / DashScope `qwen3-vl-plus`）时调用视觉模型提取，无视觉模型时展示提示。
- [ ] **粘贴文字**：粘贴任意菜谱文本解析为结构化草稿（支持 LLM 或无 Key 时本地规则解析）。
- [ ] **网页链接**：输入公开 `http(s)://` 链接抓取正文并解析；服务端校验并拦截内网/回环地址（SSRF 防护）、禁止跳转重定向、8s 超时、正文 ≤1MB。
- [ ] **口述菜谱**：提供大文本框 + 麦克风语音转文字按钮，识别结果追加至文本框并可手动微调后点击「解析为草稿」。
- [ ] **解析成功流转**：清空输入、返回添加菜谱主视图、顶部显示绿色提示「已解析为草稿，请核对后存入菜谱库」，新草稿立即出现在待确认列表顶部。

### 7.4 待确认草稿编辑、确认入库与删除
- [ ] **列表展示**：每条草稿显示 Emoji 封面、标题、来源标签（AI 生成/文字导入/网页链接/拍照识别/手动草稿）、做法、耗时，以及「编辑」「删除」两个按钮。
- [ ] **编辑与保存草稿**：点击「编辑」打开「编辑菜谱草稿」抽屉，修改标题/方式/耗时/食材/步骤后点「保存草稿」，刷新页面修改内容持久化保留且仍处于草稿状态。
- [ ] **确认入库**：在草稿编辑器点击「确认并保存」，依次调用 `PATCH /api/drafts/:id` 和 `POST /api/drafts/:id/confirm`，草稿转为正式菜谱、草稿计数减 1，并自动打开新入库菜谱的详情页。
- [ ] **删除草稿与失败恢复**：
  - 点击「删除」展开行内二次确认（「确认删除草稿「XX」？」+「取消 / 确认删除」），点击「取消」恢复按钮不删除。
  - 确认后调用 `DELETE /api/drafts/:id`，成功则移出列表并更新角标计数。
  - 若请求失败（如 503/网络错误），草稿保留不消失，抽屉底部展示 `role="alert"` 错误提示且可再次点击「确认删除」重试。
  - 后端保护：`DELETE /api/drafts/:id` 对正式菜谱 ID 返回 `404`，不会误删正式菜谱。

## 模块 10：后端 API、并发存储与跨端质量边界

### 10.1 API 路由总表（四端对齐：`server/index.js`、`netlify/functions/api.mjs`、`worker/index.js`、`cloudbase/`）

| 方法 | 路径 | 职责 | 关键异常状态码 |
| --- | --- | --- | --- |
| `POST` | `/api/session` | 校验访问码并返回 token | `401` 密码错、`429` 限流、`503` 未配置 |
| `GET` | `/api/app` | 获取完整应用状态（食材含孕期评估/菜谱匹配/草稿/家庭设置/买菜清单/AI 状态） | `401` 未鉴权 |
| `PATCH` | `/api/settings` | 更新孕期饮食守护开关、饮食备注与默认餐桌搭配 | `401` 未鉴权 |
| `POST` | `/api/recipes` | 手动新建菜谱或收藏推荐菜谱为正式菜谱 | `422` 必填缺失 |
| `POST` | `/api/meal-plan/suggest` | 按现有食材搭配一顿饭（默认 2 菜 + 主食）或规划买菜清单与菜单（AI + 本地降级） | `502` LLM 异常 |
| `PUT` | `/api/shopping-plan` | 保存/更新/清空全家共享买菜清单（含手动加减项与勾选） | `401` 未鉴权 |
| `POST` | `/api/shopping-plan/commit` | 将已勾选买回食材一键入库（含孕期评估）并可选收藏推荐菜单 | `422` 未勾选食材 |
| `POST` | `/api/audio/transcriptions` | 音频转文字（DeepSeek / DashScope） | `413` 超大、`422` 格式错、`502` 上游失败、`503` 未配置 |
| `POST` | `/api/ingredients` | 新增单条食材（含同义词归一与自动分类） | `409` 重名、`422` 空名 |
| `POST` | `/api/ingredients/batch` | 自然语言批量解析并合并写入食材 | `413` 请求超 12MB、`502` LLM 异常 |
| `PATCH` | `/api/ingredients/:id` | 修改食材名称、分类或状态 | `404` 不存在、`409` 重名、`422` 空名 |
| `DELETE` | `/api/ingredients/:id` | 删除单条食材 | `401` 未鉴权 |
| `POST` | `/api/drafts/analyze` | 文本/网页/图片解析为菜谱草稿 | `422` 空内容/非法URL/SSRF/非法图片、`502` LLM 异常 |
| `PATCH` | `/api/drafts/:id` | 保存修改后的草稿 | `404` 不存在、`422` 必填缺失 |
| `DELETE` | `/api/drafts/:id` | 删除草稿（保护正式菜谱） | `404` 不存在或已转正式 |
| `POST` | `/api/drafts/:id/confirm` | 确认草稿转为正式菜谱 | `404` 不存在或已保存 |
| `POST` | `/api/recipes/generate` | AI 根据全部或所选食材生成菜谱草稿 | `422` 参数无效/食材不存在、`502` 生成越界食材、`503` 未配置 |
| `PATCH` | `/api/recipes/:id` | 编辑正式菜谱 | `404` 不存在、`422` 必填缺失 |
| `DELETE` | `/api/recipes/:id` | 删除正式菜谱 | `404` 不存在 |
| `POST` | `/api/recipes/:id/complete` | 完成烹饪并批量更新库存、记录撤销事件 | `404` 不存在、`422` 食材不在必需清单 |
| `POST` | `/api/consumption-events/:id/undo` | 撤销烹饪造成的库存变更 | `404` 记录不存在、`409` 已撤销 |

### 10.2 存储、安全与移动端体验检查
- [ ] **首次初始化 Seed**：空库首次访问自动写入 24 种初始食材与 8 道初始正式菜谱（默认 5 道可立刻做、3 道待补食材）。
- [ ] **并发乐观锁**：Netlify Blobs 强一致读写 + `onlyIfMatch` ETag 冲突自动重试（最多 6 次，仍冲突返回 `409`）。
- [ ] **载荷与格式安全**：JSON 请求体上限 12MB（超限 `413`）、非法 JSON 返回 `400`。
- [ ] **响应式与无障碍**：

  - 弹层打开时锁定背景滚动，按 `Esc` 键关闭（请求 `busy` 时防误关）；底部导航适配 iOS 安全区。
